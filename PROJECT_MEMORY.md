## Научная цель

Проект воспроизводит и проверяет методологию surface brightness fluctuations (SBF) на
JWST/NIRCam и сверяет полученные расстояния с TRGB. Текущая статья по F150W ограничена
14 галактиками GO-3055. Основной ориентир — Jensen et al. Paper III
(`materials/2502.15935v2.pdf`); якорные индивидуальные TRGB-расстояния взяты из Paper IV
(`materials/2603.11160v1.pdf`).

Цель не в том, чтобы любой ценой найти цветовую зависимость. Главный вопрос — даёт ли
реализация SBF точные расстояния на шкале TRGB. Цвет — потенциальная поправка на звёздное
население, а не часть определения SBF.

## Замороженный F150W-анализ

Ветка `paper_work`, коммит перед началом F090W: `c3506ae` (`new graphs + corrections of Figures

`ad5785a`.

Основные файлы:

- `code/sbf-2.ipynb` — замороженный измерительный notebook F150W;
- `code/run_sbf_2_batch.py` — batch GO-3055 для Jensen-like F150W;
- `code/run_sbf_2_normalized_winsor.py` и `code/sbf2_normalized_winsor_core.py` — финальная ветвь
  нормировки/винзорирования;
- `code/sbf-2-graph.ipynb` — сводная статистика, таблицы и фигуры статьи;
- `code/sbf-2-systematics.ipynb` — тесты шума, PSF и винзорирования;
- `code/sbf-2-normalized-winsor.ipynb` — эксперимент с обрезкой после нормировки;
- `runs/sbf2_go3055/analysis/` — актуальные CSV, TeX-таблицы и фигуры.

Принятая измерительная схема:

- signal: F150W;
- population color: F090W-F150W, измерен в тех же двух кольцах;
- круговые кольца 8.2–16.4 и 16.4–32.8 arcsec для сопоставимости с Jensen;
- модель галактики — интерполяция яркости и геометрии между измеренными эллиптическими
  изофотами; Sersic нужен для заливки щелей/дыр при фите, а не как финальная модель;
- остаток `(SCI - sky - model) / sqrt(model)`;
- после нормировки выполняется симметричное винзорирование 3.5 sigma по всей
  валидной области с положительной моделью, а не отдельно по кольцам;
- это именно winsorization: выходы за порог заменяются границей, а не удаляются;
- маскированные/невалидные пиксели не входят в FFT;
- из каждого кольца перед FFT вычитается среднее, чтобы убрать DC/нулевую частоту; это
  не удаляет SBF-дисперсию;
- основной фит: `P(k) = P0 E(k) + P1`;
- модель с отдельным `N(k)` была проверена и отклонена: она ухудшала фит/давала неустойчивую
  дегенерацию;
- `kmin = 0.01, 0.03, 0.04`, `kmax = 0.25`; публикуемая ветвь берёт `kmin=0.04`;
- `E(k)` строится из PSF и реального window/mask кольца;
- PSF: STPSF 129x129, ближайший WSS OPD плюс четыре смещения по полю детектора;
- размер 129 сверен с 257; эффект невелик и выбор 129 обоснован сопоставимостью;
- `P0 = P_SBF + P_r`; `P_r` — остаточная мощность неразрешённых шаровых скоплений и фоновых галактик;
- для этой выборки `P_r/P0 < 0.67%`, поправка меньше примерно 0.007 mag; тесты `P_r=0`, adopted,
  `2P_r` и отдельных ширин GCLF не меняют вывод;
- GCLF = globular cluster luminosity function, функция светимости шаровых скоплений.

## Статистический вывод F150W

Основная калибровка заранее зафиксирована как:

- все 14 галактик;
- индивидуальные Paper IV thin-slice TRGB-модули;
- без ручного исключения объектов;
- постоянный цветонезависимый нуль-пункт как основная модель;
- линейная и нелинейные цветовые законы — только диагностика/чувствительность.

Текущие числа из аннотации статьи:

- `Mbar_150,0 = -3.208 +/- 0.024_stat +/- 0.051_common mag`;
- fitted intrinsic scatter = 0.081 mag;
- bootstrap 16–84% interval для intrinsic scatter: 0.064–0.088 mag;
- LOO-смещение модуля = -0.0010 mag;
- LOO RMS = 0.0925 mag = 4.3% по расстоянию;
- медианная внутренняя предсказанная ошибка = 0.0865 mag = 4.1%;
- с общей ошибкой абсолютной TRGB-шкалы = 0.0984 mag = 4.6%;
- RMS нормированных LOO-остатков = 1.08;
- 8/14 в пределах 1 sigma, 14/14 в пределах 2 sigma;
- линейная цветовая модель хуже: LOO RMS 0.0981 mag, Delta AICc = 3.15, bootstrap-интервал
  наклона включает ноль.

Формулировка вывода должна быть холодной: данные F150W пока не требуют цветовой зависимости;
постоянный нуль-пункт статистически конкурентоспособен и принят. Не писать просто «метод
работает» без чисел разброса и валидации.

LOO = leave-one-out: каждая галактика по очереди исключается из калибровки, а затем её расстояние
предсказывается по остальным 13. Это внутренняя кросс-валидация, не независимая внешняя
проверка.

## Научные ограничения и нельзя-выводы

- Не объявлять Virgo–Fornax step обнаружением: цвет и скопление смешаны, Fornax всего 3,
  exact permutation p около 0.23, модель со ступенькой проигрывает по AICc.
- Не объявлять NGC 1399 выбросом в основном опыте. Она отклоняется примерно на 2.2 sigma;
  красивая парабола без неё — постфактум-тест чувствительности.
- Основные расстояния: индивидуальные Paper IV thin-slice. Thick-slice — обязательная проверка
  чувствительности. Средние по Virgo/Fornax — буквальное сравнение с Paper III, не основа.
- Сравнение Jensen 2015 F160W есть только для 5 общих галактик. Не смешивать его с Paper III F110W.
- Внутренние кольца визуально/статистически стабильнее внешних, но оба оставлены для
  повторения геометрии Jensen. Одни и те же угловые кольца охватывают разные физические радиусы.
- Показатель `M150_model_aperture` — не полная светимость, а светимость модели внутри 32.8 arcsec.
  График связи SBF с ней — исследовательский; общая корреляция p=0.20, после цветового вычитания
  p около 0.056; обнаружением не считать.
- Внутренняя пыль, K-поправка и космологическое потускнение оценены как малые для этих
  близких E/S0; количественные границы есть в статье.

## Ошибки F150W

Индивидуальная ошибка измерения apparent SBF складывается в квадратуре из:

- разброса спектрального фита/окон `P(k)`;
- разброса по PSF-реализациям;
- фона;
- неопределённости `P_r`;
- погасания в Млечном Пути.

Для точки абсолютной калибровки добавляется индивидуальная ошибка TRGB-модуля. Для предсказания
расстояния также нужны intrinsic scatter калибровки и конечная точность нуль-пункта. Общая
ошибка абсолютной TRGB-шкалы не уменьшается от усреднения галактик и должна показываться отдельно.

Измерительные столбики на графике могут быть маленькими, но реальный LOO-разброс больше из-за
intrinsic scatter и калибровочной неопределённости. Не смешивать «точность измерения `mbar`» с
«точностью предсказанного расстояния».
