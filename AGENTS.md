# Рабочие соглашения проекта

- Перед содержательной работой прочитать `PROJECT_MEMORY.md`: там зафиксированы научные решения, состояние пайплайнов и текущие TODO.
- Команды для пользователя всегда давать из рабочей папки `code/`.
- Считать, что виртуальное окружение `astro_env` уже активировано; Python запускается командой `py`.
- Не добавлять `MPLBACKEND=Agg` в команды, которые должен запускать пользователь.
- Для служебных запусков Codex с Matplotlib без GUI использовать backend `Agg`, чтобы macOS не убивала дочерний Python.
- Не запускать ячейки научных notebook без прямого разрешения пользователя; допустима статическая проверка кода.
- Все долговечные продукты проекта сохранять только внутри рабочей директории, а не в `/private/tmp`.
