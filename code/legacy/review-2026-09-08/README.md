загрузчиком), обе актуальные измерительные ветви, анализ, генераторы рисунков,
систематические проверки и общие тесты campaign/runtime/status. Последние
по-прежнему проверяют также архивный runner, импортируя его явно из `sbf3/`.

настройки и предположения об окружении не являются инструкцией актуального релиза.

модулей после переноса, без изменения научного метода.

Команды из `code/`, без запуска научных notebook:

```bash
py legacy/review-2026-09-08/sbf3/run_sbf_batch.py --help

```
