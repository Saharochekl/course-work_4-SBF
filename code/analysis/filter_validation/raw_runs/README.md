# Raw F356W/F277W validation runs

These directories were moved intact from the former temporary execution area
into the project workspace on 2026-07-16. They contain the batch log/result JSON
and all FITS/CSV products produced by the pre-stage-dump version of
`sbf-3.ipynb` for NGC 1380 and NGC 1404.

The absolute paths embedded in the historical result JSON and log still point
to their original temporary execution location. The actual files are stored
under the adjacent `products/` trees in this directory. New standalone runs of
`sbf-3.ipynb` write their stage products next to the signal input FITS by
default.
