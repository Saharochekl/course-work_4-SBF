# Флуктуации поверхностной яркости JWST — GO-3055

Измерение SBF в F150W и F090W для 14 галактик, калибровка по TRGB,
сравнение расстояний и подготовка рисунков. [Английская версия](Readme.md).

## Структура

В корне `code/` — два скрипта и три рабочих ноутбука:

- `download.py` — проверка и скачивание изображений/OPD.
- `process.py` — запуск обработки F150W и F090W.
- `sbf-2.ipynb` — общий шаблон обработки изображений и ручного просмотра.
- `sbf-2-graph.ipynb` — анализ и графики F150W.
- `sbf-f090w-graph.ipynb` — анализ и графики F090W.

Вспомогательный код разнесён по обычным папкам, без симлинков:

| Путь | Содержание |
|---|---|
| `code/sbf/` | Рабочие обработчики, загрузчики, кэширование и проверки |
| `code/figures/` | Построители рисунков, таблиц и F090W-ноутбука |
| `code/config/` | Манифесты точных продуктов и галактик |
| `code/reference/` | Входные литературные таблицы |
| `code/tests/` | Короткие тесты без научных прогонов |
| `runs/F150W/source/` | Модели, маски, PSF и исходные измерения |
| `runs/F150W/spectra/` | Финальные нормированные остатки и спектральные результаты |
| `runs/F150W/analysis/` | Калибровки, таблицы и входы графиков |
| `runs/F090W/` | Исходная обработка, спектры, итоговые продукты и анализ F090W |
| `data/` | Загруженные изображения, OPD и опорные данные |
| `texts/paper_work/materials/` | Рисунки статьи и список их источников |
| `.cache/` | Восстановимые служебные кэши |
| `trash/2026-09-09/removed/` | Отложенные для удаления экспорты и старый код, только локально |

Три ноутбука оставлены намеренно: общий измерительный шаблон и отдельный анализ
каждого фильтра. Личные заметки, окружение, архивы и большие продукты в Git не идут.
Старый код перенесён в `trash/2026-09-09/removed/code/legacy/` и больше не лежит
в рабочем `code/`. Обработка его не импортирует и не требует ссылок на него.

## Запуск

Все команды — **из папки `code/`**, окружение уже активировано.
`py` — локальное имя Python; при его отсутствии используйте `python3`.
Рабочая платформа — POSIX; проверки выполнялись на macOS с Python 3.13.

```bash
py -m pip install -r ../requirements.txt
py -m sbf.check_project_layout
```

### 1. Подготовить данные

```bash
py download.py images --program 3055
py download.py images --program 3055 --download
py download.py opd --program 3055 --download
```

Без `--download` загрузчик только проверяет локальные файлы.
Точные продукты указаны в `config/targets_go3055_manifest.csv`.
Дополнительный манифест GO-7763 не входит в текущую выборку статьи.
Отдельно нужны опорные файлы STPSF: задайте `STPSF_PATH` либо положите их
в `../data/stpsf-data/`. OPD их не заменяют. Используются готовые i2d;
калибровка исходных детекторных экспозиций здесь не выполняется.

### 2. Обработать

```bash
py process.py --dry-run
py process.py --filter F150W
py process.py --filter F090W
```

Первая команда только печатает план. Следующие запускают длительные вычисления;
готовые подходящие продукты и кэши используются повторно.
Первый полный F090W требует исходные продукты F150W, поэтому порядок именно такой.
`py process.py` запускает оба фильтра в этом порядке.

Для отдельного этапа F150W есть `--stage source` и `--stage spectra`.
Для одной галактики — `--galaxies "NGC 4636"`.
F090W работает с `--stage all`, пропуская готовые этапы по кэшу.
Расширенные параметры отдельных обработчиков доступны через
`py -m sbf.run_sbf_f090w --help` и аналогичные модули в `sbf/`.

Проверка метаданных и наличия продуктов без повторного измерения:

```bash
py -m sbf.check_project_layout --with-products
```

### 3. Проанализировать или перерисовать

Откройте `sbf-2-graph.ipynb` для F150W или `sbf-f090w-graph.ipynb` для F090W.
Ячейки запускаются сверху вниз, картинки выводятся внутри ноутбуков.
Смена цвета, фона или подписей не требует повторной обработки галактик.

Рисунки статьи из готовых результатов:

```bash
py -m figures.build_go3055_article_figures
py -m figures.publish_article_assets --check
```

Остальные построители и их входы описаны в
[документации анализа](docs/analysis.rst).
Модуль `figures.build_sbf_f090w_graph_notebook` пересоздаёт ноутбук —
**не запускайте его поверх нужных ручных изменений**.

## Воспроизводимость и очистка

В релиз идут рабочие скрипты и ноутбуки, пакеты, тесты, манифесты,
литературные входы, документация и материалы публикации.
Из Markdown отслеживаются только два корневых README; личные заметки остаются локальными.
Игнорирование в Git не означает, что файл можно удалить:
для некоторых рисунков и возобновления расчётов нужны модели, маски,
рабочие остатки, PSF, таблицы и журналы оценки фона.

Подтверждённые лишние экспорты, старые кэши и архивный код уже перенесены в
`trash/2026-09-09/removed/` с сохранением прежних относительных путей.
Окончательно удаляет их владелец; само перемещение внутри диска место не освобождает.
Текущие научные таблицы и принятые входы обработки остаются в `runs/` и `data/`.

Побитовое воспроизведение на произвольном компьютере пока не обещается.
Нужны те же i2d/OPD, опорные файлы STPSF и согласованные версии зависимостей.
В `requirements.txt` закреплены прямые зависимости, но не весь транзитивный стек
и внешние данные. Сохранённые выводы ноутбуков относятся к предыдущим запускам,
а не к автоматическому выполнению текущей ревизии.
